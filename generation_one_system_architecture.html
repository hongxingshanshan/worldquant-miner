🌐 系统概述

WorldQuant Miner Generation One 是一个基于 LLM 的 Alpha 表达式自动挖掘系统。它利用本地 Ollama 或云端 LLM 服务生成 Alpha 表达式，并通过 WorldQuant Brain API 进行模拟验证和提交。

🎯 核心功能
  • Alpha 生成: 基于 LLM 的智能 Alpha 表达式生成
  • 本地验证: 语法检查、规则预检、字段验证
  • 模拟提交: 对接 WorldQuant Brain API 进行模拟
  • 自适应优化: 分析失败原因并优化表达式
  • 多臂老虎机: 智能选择最佳模拟参数配置
  • Web 监控: 实时监控挖掘进度和结果

🔄 数据流程

Alpha 生成流程

1
编排器启动 (AlphaOrchestrator)
加载配置、初始化 LLM 客户端、启动 Web Dashboard
⬇️
2
生成周期 (AlphaGenerator.generate_alpha_batch)
加载成功模式 → 加载知识库 → 构建提示词 → 调用 LLM 生成表达式
⬇️
3
本地验证 (AlphaValidator.validate)
语法检查（括号匹配、操作符有效性）→ 规则检查（外层排名、市值标准化）→ 字段验证
⬇️
4
入队 (AlphaQueue)
区分 generated 和 optimized 来源，等待消费
⬇️
5
消费者线程 (AlphaSimulator)
批量获取 Alpha → 提交模拟 → 记录结果
⬇️
6
优化循环 (AlphaOptimizer)
分析失败原因 → 构建优化提示词 → 生成优化版本
⬇️
7
提交 (ImprovedAlphaSubmitter)
检查 hopeful_alphas.json → 验证相关性 → 提交到 WQ 平台

验证流程

🔍 本地预检
  • has_outer_rank() - 检查外层排名操作符
  • has_neutralization_or_cap_norm() - 检查中性化/市值标准化
  • type_compatible() - 检查操作符类型兼容性
🌐 远程模拟
  • POST /simulations - 创建模拟
  • GET /simulations/{id} - 轮询结果
  • 解析 is_checks (LOW_SHARPE, LOW_FITNESS, etc.)

提交流程

1
加载候选 Alpha
从 hopeful_alphas.json 加载 (fitness > 0.5, sharpe > 1.0)
⬇️
2
获取已提交列表
GET /users/self/alphas?status=SUBMITTED
⬇️
3
相关性检查
POST /alphas/{id}/check-correlation (prod_correlation < 0.7)
⬇️
4
提交 Alpha
POST /alphas/{id}/submit
⬇️
5
更新缓存
更新 submitted_alphas_cache.json

  • API 返回: 美国东部时间 (EST/EDT，如 -04:00)

  • 多版本支持: 从基础版到高级优化版，满足不同需求
  • 本地验证: 减少无效 API 调用，节省时间和配额
  • 自适应优化: 从失败中学习，持续改进生成策略
  • 智能参数选择: 多臂老虎机算法优化模拟参数
  • 实时监控: Web Dashboard 提供可视化监控界面
  • 数据持久化: MySQL 数据库存储 Alpha 历史和优化记录
  • 增量同步: 智能时区处理，高效同步 WQ API 数据
⚠️ 注意事项
  • WorldQuant Brain API 有模拟限制（5分钟/次），需合理使用本地验证
  • Ollama 服务需要足够的 VRAM，建议使用模型舰队管理
  • 子进程管理需要正确处理退出信号，避免僵尸进程
  • 凭证文件需要妥善保管，不要泄露或提交到版本控制
